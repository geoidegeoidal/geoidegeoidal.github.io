## Why
The owner reports an overly close camera and poor labels, and asks to elevate the game experience. Current fixed 1.7/1.45 scale magnifies both art and text, obscures orientation and clips labels.
## What Changes
- Wider responsive default camera, user zoom and stable follow.
- Screen-sized landmark labels, nearby NPC names only and clear context controls.
- Illustrated village overview with selectable destinations, actual guided walking, visible routes and cancellation.
- Preserve character proportions, factual content, music and classic homepage.
## Capabilities
### New Capabilities
- world-navigation: camera, labels and guided travel.
### Modified Capabilities
None.
## Impact
RPG markup, styles, rendering/model and browser regression checks; no production dependency.
