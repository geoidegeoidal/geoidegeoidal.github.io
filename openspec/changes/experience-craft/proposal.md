## Why
The owner finds both alternative views below professional quality: the RPG content still resembles web modals and the console lacks terminal behavior, guidance and typographic craft. The classic portfolio must remain the default homepage, with a personal invitation to the alternatives.

## What Changes
- Rewrite the homepage invitation while preserving the classic hero and primary routes.
- Add authored pixel interiors, richer terrain and ambient motion, orientation map, illustrated RPG reading views and opt-in original music with volume and lifecycle controls.
- Replace the console's website/sidebar layout with a full terminal session: local file tree, prompt with current directory, ls/cd/cat/tree/pwd/help, existing Spanish aliases, command completion/history, keyboard shortcuts, contextual guided commands and restrained reveal animation.
- Preserve real content, limitations and accessible direct reading; audio and animation pause when hidden and respect user controls.

## Capabilities
### New Capabilities
- `crafted-alternatives`: classic-first navigation, RPG reading/audio and terminal interaction.

## Impact
Jekyll static views and native browser APIs; new room art and self-hosted font, no backend or production framework. Existing curated datasets remain factual authority.
