# Atlas cartográfico

Datos geográficos de Natural Earth, escala 1:110m, dominio público.
Fuente: https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_admin_0_countries.geojson
Licencia: https://www.naturalearthdata.com/about/terms-of-use/

atlas.json conserva anillos de países y una muestra de puntos terrestres de 2 grados. Coordenadas redondeadas a dos decimales, para esta representación de escala mundial. La vista usa proyección ortográfica; no es una herramienta de medición territorial.

atlas.svg es la vista estática derivada de los mismos datos. Se conserva como alternativa sin JavaScript o si falla la carga del atlas interactivo. Canvas y los datos se sirven desde este sitio, sin servicios ni tokens externos.
